# Retail Sales & Profitability Dashboard Using  Excel

## 📌 Project Overview

This project focuses on analysing retail sales data using Microsoft Excel to understand sales performance, profitability, product performance, and regional trends.

The objective is to transform raw sales data into meaningful business insights using Excel formulas, data analysis techniques, PivotTables, charts, and an interactive dashboard.

This project is being developed as part of my learning journey in Data Analytics and Business Analysis.

## 🎯 Business Problem

Retail businesses generate large amounts of sales data but may struggle to identify their best-performing products, profitable regions, sales trends, and areas that need improvement.

This project aims to answer the following business questions:

- Which products and categories generate the highest sales?
- Which regions perform best and worst?
- What are the overall sales and gross profit?
- How do sales change month by month?
- Which sales channels perform best?
- Are discounts affecting profitability?
- What actions can management take to improve business performance?

## 📁 Dataset

The project uses a synthetic retail sales dataset containing 400 transactions for 2025.

The dataset includes:

- Order ID
- Order date
- Customer ID
- Product ID and product name
- Product category
- Region
- Sales channel
- Salesperson
- Quantity
- Unit price
- Discount rate
- Order status

Additional worksheets provide product costs, list prices, and regional targets.

**Note:** The dataset is synthetic and created for educational purposes. It does not contain real customer transaction records.
